# 알림

알림은 화면을 지켜보지 않아도 무언가가 사용자의 주의를 필요로 할 때, 즉 세션이 완료되었거나, 오류가 발생했거나, 질문했거나, 무언가를 할 권한이 필요할 때 알려줍니다. **Settings → OpenChamber → Notifications**에서 설정합니다.

## 켜기

1. **Settings → OpenChamber → Notifications**를 엽니다.
2. 브라우저나 시스템이 요청하면 알림을 허용합니다.
3. 알림받고 싶은 내용을 선택합니다.
   - 세션 **완료**
   - 세션 **오류** 발생
   - 세션이 **질문**할 때
   - 세션이 **권한**을 필요로 할 때
   - **하위 작업** 완료

## 전달 방식

- **데스크톱**에서는 네이티브 시스템 알림을 받습니다
- **브라우저 또는 설치된 앱**에서는 웹 푸시 알림을 받으므로 탭이 백그라운드에 있어도 도착합니다
- **iPhone과 Android 앱**에서는 푸시 알림을 받습니다. 내용은 서버와 휴대폰 사이에서 암호화되므로, 중간의 푸시 서비스는 일반적인 제목만 봅니다. 휴대폰에서는 각 알림에 세션 이름과 일어난 일, 즉 에이전트의 답변, 질문 또는 실행하려는 명령이 표시됩니다

자동 수락으로 설정된 세션은 권한 알림으로 귀찮게 하지 않습니다.

## 알림 센터

헤더의 종 아이콘에는 서버가 지난 7일 동안 보낸 모든 알림이 최신순으로 나옵니다. 앱을 보고 있는 동안 온 알림도 포함됩니다. 읽지 않은 알림에는 점이 붙고, 종 아이콘에 그 수가 표시됩니다. 세션을 열면 그 세션의 알림이 모든 기기에서 읽음으로 바뀝니다. 알림을 클릭하면 해당 세션으로 이동하고, 읽지 않은 알림과 당신을 기다리는 알림(질문, 권한, 오류)만 걸러 볼 수도 있습니다.

다른 곳을 보는 동안 일어난 일도 남습니다. 실행 중인 채팅을 끊은 OpenCode 재시작(항목을 열면 각 채팅이 보입니다), 끝났거나 승인을 기다리는 수정 루프, 충돌로 멈춘 스택 PR 리스택, 실패한 예약 작업, OpenChamber와 OpenCode 업데이트입니다. **확인 필요**에는 읽었든 아니든 아직 당신을 기다리는 것이 보입니다. 질문과 권한은 답할 때까지, 재시작은 모든 채팅을 이어 가거나 닫을 때까지, 수정 루프는 승인할 때까지, 리스택은 다시 진행될 때까지, 업데이트는 설치될 때까지 남습니다. 오류는 읽을 때까지 남습니다. 목록은 스스로 정리됩니다. 완료된 턴은 확인하거나 그 채팅에 다시 쓰면 **기록**으로 옮겨지고, 질문과 권한은 답하면 옮겨집니다. 7일이 지났거나 최신 200개를 넘는 알림은 삭제됩니다. 한 채팅의 완료된 턴 여러 개는 한 줄로 묶이며, 줄 끝의 버튼으로 삭제할 수 있습니다.

[분류 제공자](/ko/classification-providers/)를 설정하면 Jev가 끝난 턴도 하나씩 읽습니다. 완료된 것 같거나 할 일이 없는 턴은 알림이나 푸시 없이 알림 센터로 가고, 나머지는 몇 초 늦게 전처럼 알립니다. 질문, 권한, 오류는 Jev를 거치지 않습니다. **끝난 턴 중 어떤 것을 알릴지 Jev가 결정** 을 끄면 사용하지 않습니다.

## 문구 맞춤 설정

각 알림 종류에는 에이전트 이름과 모델 같은 필드를 사용해 편집할 수 있는 제목과 메시지 템플릿이 있습니다. 또한 알림이 짧게 유지되도록 마지막 메시지를 얼마나 포함할지에 대한 제한도 있습니다.
