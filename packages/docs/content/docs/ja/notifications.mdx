# 通知

通知は、画面を見張っていなくても注意が必要なことを知らせます。セッションの完了、エラー、質問、何かを行うための権限要求などです。**Settings → OpenChamber → Notifications** で設定します。

## オンにする

1. **Settings → OpenChamber → Notifications** を開きます。
2. ブラウザまたはシステムが求めたら通知を許可します。
3. 何について通知を受けたいか選びます。
   - セッションが**完了**した
   - セッションで**エラー**が起きた
   - セッションが**質問**した
   - セッションが**権限**を必要としている
   - **サブタスク**が完了した

## 通知の届き方

- **デスクトップ**では、ネイティブのシステム通知を受け取ります
- **ブラウザまたはインストール済みアプリ**では、Web Push 通知を受け取るため、タブがバックグラウンドでも届きます
- **iPhone と Android のアプリ**ではプッシュ通知が届きます。内容はサーバーとスマートフォンの間で暗号化されるため、途中のプッシュサービスには汎用的なタイトルしか見えません。スマートフォンでは各通知にセッション名と起きたこと（エージェントの返答、質問、実行したいコマンド）が表示されます

自動承認に設定されたセッションでは、権限通知で何度も邪魔されることはありません。

## 通知センター

ヘッダーのベルには、サーバーが過去 7 日間に出したすべての通知が新しい順に並びます。アプリを開いていた間に届いたものも含まれます。未読にはドットが付き、ベルに未読の数が表示されます。セッションを開くと、その通知はすべてのデバイスで既読になります。通知をクリックするとそのセッションに移動します。未読と、あなたの対応を待っているもの (質問、権限、エラー) で絞り込むこともできます。

ほかの画面を見ている間に起きたことも残ります。実行中のチャットを止めた OpenCode の再起動 (項目を開くと各チャットが表示されます)、完了した、または承認を待っている修正ループ、競合で止まったスタック PR のリスタック、失敗したスケジュールタスク、OpenChamber と OpenCode のアップデートです。**対応待ち** には、既読かどうかに関係なく、まだあなたを待っているものが表示されます。質問や権限は回答するまで、再起動はすべてのチャットを続行または閉じるまで、修正ループは承認するまで、リスタックは再開するまで、アップデートはインストールするまで残ります。エラーは読むまで残ります。 一覧は自動で片付きます。完了したターンは、見たとき、またはそのチャットに再び書き込んだときに **履歴** へ移り、質問や権限は回答したときに移ります。7 日より古いものと、新しい 200 件を超えたものは削除されます。同じチャットの完了したターンは 1 行にまとまり、行の末尾のボタンで削除できます。

[分類プロバイダー](/ja/classification-providers/)を設定していると、Jev が完了した各ターンも読みます。完了したように見えるターンや対応不要なターンは、アラートやプッシュなしで通知センターに入ります。それ以外はこれまでどおり、数秒遅れて通知されます。質問、権限、エラーは Jev を通りません。オフにするには **完了したターンのどれを通知するか Jev に判断させる** を切ります。

## 文言をカスタマイズする

通知の種類ごとに、エージェント名やモデルなどのフィールドを使ったタイトルとメッセージテンプレートを編集できます。直近メッセージをどれだけ含めるかにも上限があり、通知が短く保たれます。
