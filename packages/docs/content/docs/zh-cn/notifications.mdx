# 通知

通知会在有事情需要你关注时告诉你，这样你就不必盯着屏幕 — 会话完成了、遇到错误、提出了问题，或需要权限来做某件事。在 **Settings → OpenChamber → Notifications** 中设置它们。

## 开启它们

1. 打开 **Settings → OpenChamber → Notifications**。
2. 当你的浏览器或系统询问时，允许通知。
3. 选择你想被告知哪些事项：
   - 会话**完成**
   - 会话遇到**错误**
   - 会话**提出问题**
   - 会话需要**权限**
   - **子任务**完成

## 它们如何送达你

- 在**桌面端**，你会收到原生系统通知
- 在**浏览器或已安装的应用**中，你会收到网页推送通知，因此即使标签页在后台它们也能送达
- 在 **iPhone 和 Android 应用**中，你会收到推送通知。通知内容在你的服务器和手机之间加密，途中的推送服务只能看到通用标题。在手机上，每条通知会显示会话名称和发生的事情：智能体的回复、它的提问，或它想运行的命令

设置为自动接受的会话不会用权限通知来打扰你。

## 通知中心

页头的铃铛会列出服务器过去 7 天发出的所有通知，最新的在前，包括你在应用里时收到的那些。未读通知带一个圆点，铃铛上显示未读数量。打开一个会话后，它的通知会在所有设备上标为已读。点一条通知即可跳到对应会话，也可以只看未读或等你处理的通知：提问、权限请求和错误。

你在看别处时发生的事也会留在这里：打断了运行中对话的 OpenCode 重启（打开这条通知可看到每个对话）、已结束或等你批准的修复循环、因冲突停下的堆叠 PR 重新堆叠、失败的计划任务，以及 OpenChamber 和 OpenCode 的更新。**等你处理** 显示仍在等你的通知，不论是否已读：提问或权限请求直到你回答，重启直到每个对话都继续或关闭，修复循环直到你批准，重新堆叠直到它继续，更新直到安装完成。错误会一直留到你读过为止。 列表会自动整理：已完成的轮次在你看过或在该对话中再次发言后移入 **历史**，提问或权限请求在得到回答后移入。超过 7 天或超出最新 200 条的通知会被删除。同一对话的多个已完成轮次合并为一行，行末的按钮可将其移除。

设置了[分类提供方](/zh-cn/classification-providers/)后，Jev 也会读每个完成的轮次。看起来已完成或无需处理的轮次进入通知中心，不弹提醒也不推送；其他轮次照常提醒，只是晚几秒。提问、权限请求和错误从不经过 Jev。关闭 **让 Jev 决定哪些完成的轮次需要提醒你** 即可停用。

## 自定义措辞

每种通知都有一个标题和消息模板，你可以编辑它们，使用诸如智能体名称和模型之类的字段。还有一个对最后一条消息包含多少内容的限制，以使通知保持简短。
